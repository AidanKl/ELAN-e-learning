Een overzicht van wie je waarvoor benadert. Naslag bij alle fasen.

!!! warning "Verifieer de actualiteit"

| Vraag / situatie | Aanspreekpunt |

| CBS-RA & awareness test | CBS-helpdesk + ELAN-contactpersoon |
| Ethische vragen / METC | ELAN-kernteam + METC-secretariaat |
