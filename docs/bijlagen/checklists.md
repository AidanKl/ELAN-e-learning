# Checklists per fase


Afvinkbare checklists als naslag. Gebruik ze tijdens je traject.

## Oriëntatie (Fase 1)
- [ ] ELAN-DCC documentatie gelezen
- [ ] Oriëntatiegesprek met datamanager gepland
- [ ] Dataklasse bepaald (huisarts / + ziekenhuis / + CBS)
- [ ] Omgeving bepaald (I-schijf / CBS-RA / beide)

## Voorbereiding (Fase 3)
- [ ] Aanvraag eerst in Word uitgeschreven
- [ ] ELAN-nWMO-template gebruikt
- [ ] CBS-RA expliciet vermeld (indien van toepassing)
- [ ] Ticket gekoppeld aan een werkpakket + PI geïnformeerd
- [ ] Statusupdate ingepland na 2 weken

## Data-ontvangst (Fase 4 & 5)
- [ ] Validatie uitgevoerd (mappen, variabelenamen, N, tijdsvenster, missings)
- [ ] Filterspecificaties opgevraagd bij data-manager
- [ ] Records met EndDate verwijderd / ontdubbeld
- [ ] Niet gestart met analyse vóór alle goedkeuringen binnen waren

## Analyse (Fase 6)
- [ ] Scriptstructuur aangehouden (inladen / bewerken / analyse / output)
- [ ] ICPC niet als diagnose gebruikt zonder validatie
- [ ] Praktijkvariatie meegenomen in de methode
- [ ] Output voldoet aan CBS-celgrootte-eisen

## Afronding & disseminatie (Fase 7 & 8)
- [ ] Manuscript ≥2 weken vóór submission gedeeld met PI + Hoofd ELAN + elan@lumc.nl
- [ ] Na publicatie: datamanager, CBS en (PhD) Converis geïnformeerd
- [ ] Infrastructuurpapers geciteerd
- [ ] Toegang correct beëindigd bij de datamanager
