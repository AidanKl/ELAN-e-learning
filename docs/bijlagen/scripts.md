!!! tip "Deel je eigen script"
    Heb je een script ontwikkeld dat ook voor anderen nuttig is? Stuur het naar Aidan Kloots met: onderwerp, omgeving (I-schijf / CBS-RA / beide), taal, korte beschrijving en of het is getest. Ook scripts die juist NIET werken zijn waardevol.
