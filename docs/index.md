# Welkom bij de ELAN E-learning

## Wat gebeurt er in deze fase?

Deze e-learning leidt je stap voor stap door het werken met **ELAN-data** — van het eerste idee tot de publicatie van je resultaten. De cursus is bedoeld voor **startende onderzoekers** die voor het eerst (of na een pauze) met ELAN aan de slag gaan.

ELAN (Extramuraal LUMC Academisch Netwerk) is een geïntegreerde data- en kennisinfrastructuur met geanonimiseerde zorgdata van ruim een miljoen inwoners in de regio Den Haag en Leiden.

## Hoe deze e-learning werkt

De cursus volgt de **acht fasen** van een onderzoekstraject. Je doorloopt ze het beste op volgorde. Onderaan elke module vink je af wat je hebt gelezen; daarna komt de knop naar de volgende fase vrij.

!!! tip "Tip"
    Gebruik het menu links om snel naar een fase te springen waar je naar wilt teruggrijpen.
